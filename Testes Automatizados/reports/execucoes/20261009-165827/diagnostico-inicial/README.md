# Diagnóstico da primeira execução

Esta primeira execução revelou que a automação interpretava incorretamente o desconto exibido como "- R$ 10,00". O sinal representa a dedução no resumo; o valor de desconto esperado continua positivo. As comparações de desconto dessa execução não são usadas para concluir falha do produto. A leitura foi corrigida e os 15 casos foram repetidos na execução final. Os registros originais estão preservados.
